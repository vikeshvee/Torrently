⚡ Quick Start

Run torrently in any terminal window (Terminal.app, iTerm2, VS Code, etc.):

torrently list

📖 Command Reference

torrently list

List all torrents with name, infoHash, progress %, speeds, and peer count.

torrently list --json
torrently add <target>

Add a magnet link, .torrent file path, or URL. Options: --path <dir>, --paused.

torrently add ./movie.torrent --path ~/Movies
torrently pause <infoHash|--all>

Pause a single downloading torrent by hash or all active torrents.

torrently pause 8c0d12e4
torrently resume <infoHash|--all>

Resume downloading selected files in a paused torrent or all torrents.

torrently resume 8c0d12e4
torrently files <infoHash>

Inspect all files inside a multi-file torrent with index numbers and status.

torrently files 8c0d12e4
torrently select / deselect

Select or skip specific subfiles. Auto-pauses if all deselected; auto-resumes on select.

torrently deselect 8c0d12e4 1
torrently speed [--watch]

Display live download and upload network throughput with live ticker option.

torrently speed -w
torrently status-bar [on|off]

Inspect or toggle the live speed meter ticker in the macOS menu bar.

torrently status-bar on
torrently verify <infoHash>

Force piece re-check and integrity verification of downloaded files on disk.

torrently verify 8c0d12e4
torrently remove <infoHash>

Remove torrent from queue. Pass -d or --delete-files to delete data from disk.

torrently rm 8c0d12e4
Tip: Type torrently --help in terminal anytime for quick syntax help.

User Guide & Documentation

1. Instant In-Flight Video Streaming

Click the Stream button on any audio or video file inside the multi-file accordion to begin playback instantly. Torrently prioritizes pieces sequentially so you can watch HD movies while downloading.

2. Selective File Downloading

Expand any torrent by clicking anywhere on the row. Uncheck unwanted files (e.g. sample clips, readme text) to download only the files you need. Progress and completion are calculated strictly from selected files.

3. Peer Swarm Geolocation & Node Blocking

Click on the Seeds / Peers text on any torrent card to open the Swarm Inspector. View peer country flags, client software, transfer rates, and ban toxic or slow nodes with one click.

4. Subfile Size Display Modes

Click on any file size in the accordion to toggle between Total Size (e.g. 1.4 GB), Remaining Size (e.g. 320 MB left), and Total & Downloaded (e.g. 1.1 GB / 1.4 GB).
