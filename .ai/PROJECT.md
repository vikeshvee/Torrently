# Project Overview - Torrently

**Torrently** is a state-of-the-art, cross-platform desktop torrent application engineered specifically for instantaneous video streaming. By merging modern BitTorrent peer-to-peer protocols with an embedded, low-latency HTTP range server and a sleek visual desktop client, Torrently eliminates the wait time of downloading media torrents.

---

## Key Features

1. **Instant Video Streaming**: Start watching HD/4K movies or episodes within seconds of adding a torrent or magnet link.
2. **Sequential Piece Engine**: Intelligent piece request engine prioritizes media headers, index blocks, and seek targets dynamically.
3. **Cross-Platform Native App**: Native desktop performance and visual integration on macOS (Apple Silicon & Intel), Windows 10/11, and Linux (Ubuntu/Fedora/Arch).
4. **Rich Visual Interface**: Deep space dark mode, glassmorphic UI panels, real-time download/upload network graphs, peer location maps, and interactive video playback controls.
5. **Smart Bandwidth Allocation**: Custom speed limits, background throttling, and priority queues for multi-torrent downloads.
6. **External Player Support**: Option to stream directly inside the Torrently native player or cast to external applications (VLC, IINA, MPV) or AirPlay/Chromecast devices.

---

## Target Audience

- Users who want to watch video torrents without waiting for complete downloads.
- Media enthusiasts seeking a clean, ad-free, modern torrent client.
- Developers looking for an open, modular BitTorrent desktop architecture.
